# 05 LVGL SD Image

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Loads image files from a TF card and presents them through the LVGL interface.

## Hardware Required

- ESP32-S3-Touch-LCD-1.47 development board

## How to Run

idf.py set-target esp32s3 build flash monitor

## Expected Result

The display shows the LVGL interface and images read from the TF card.

## Troubleshooting

Insert a TF card containing the expected image files before starting the example.
