# 04 LVGL 图片

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Displays the bundled image inside an LVGL interface.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

idf.py set-target esp32s3 build flash monitor

## 预期现象

The display renders the bundled image and the LVGL interface.

## 常见问题

The example requires the board display.
