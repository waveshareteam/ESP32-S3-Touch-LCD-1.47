# 03 LVGL Example

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Starts the LVGL interface with the board display, touch controller and status tiles.

## Hardware Required

- ESP32-S3-Touch-LCD-1.47 development board

## How to Run

idf.py set-target esp32s3 build flash monitor

## Expected Result

The display shows the LVGL interface and responds to touch input.

## Troubleshooting

The display and touch controller must be connected to the board.
