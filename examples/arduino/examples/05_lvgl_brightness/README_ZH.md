# 05 LVGL 亮度

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Controls the display backlight from an LVGL interface.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

Arduino IDE

## 预期现象

The display shows the brightness interface and changes the backlight level.

## 常见问题

The example requires the board backlight pin wiring.
