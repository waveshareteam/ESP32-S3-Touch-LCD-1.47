# 04 LVGL Battery

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Shows battery information in an LVGL interface.

## Hardware Required

- ESP32-S3-Touch-LCD-1.47 development board

## How to Run

Arduino IDE

## Expected Result

The display shows the battery information interface.

## Troubleshooting

Battery readings depend on the board power and battery circuit.
