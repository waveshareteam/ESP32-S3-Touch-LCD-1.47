# 06 LVGL 图片

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Displays the bundled image through an LVGL v8 interface.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

Arduino IDE

## 预期现象

The display renders the bundled image.

## 常见问题

Install LVGL v8 and the bundled Arduino_GFX library before compiling.
