# 03 LVGL Arduino v8

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Runs an LVGL v8 interface using the board display and touch controller.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

Arduino IDE

## 预期现象

The display shows the LVGL interface and responds to touch input.

## 常见问题

Install the Arduino-ESP32 version and bundled libraries listed in the repository README.
