# 01 GFX Hello World

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Initializes the JD9853 display with Arduino_GFX and draws animated Hello World text.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

Arduino IDE

## 预期现象

The display shows Hello World text in changing positions and colors.

## 常见问题

Select the FQBN from .github/product.json and connect the board over USB.
