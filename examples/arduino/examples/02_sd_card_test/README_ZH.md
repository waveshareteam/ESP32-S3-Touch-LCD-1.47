# 02 SD 卡测试

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Tests TF card access from an Arduino sketch.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

Arduino IDE

## 预期现象

The serial monitor reports the TF card test result.

## 常见问题

Insert a formatted TF card before uploading the sketch.
