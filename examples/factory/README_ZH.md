# 出厂固件

[English](README.md) | [简体中文](README_ZH.md)

## 功能

Runs the complete factory LVGL demonstration with display, touch and TF card features.

## 硬件需求

- ESP32-S3-Touch-LCD-1.47 开发板

## 怎么运行

idf.py set-target esp32s3 build flash monitor

## 预期现象

The board starts the factory demonstration interface.

## 常见问题

This source project is intended for the matching ESP32-S3-Touch-LCD-1.47 hardware.
